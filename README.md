# RepoTomo（レポトモ）

講義資料をスライドで復習し、レポートの構成と下書き作りまで手伝う学習用Webアプリです。
科目を問わず使えます（マーケティング専用ではありません）。

## できること

| 機能 | 内容 |
|---|---|
| 講義ライブラリ | PDF・テキストをドロップすると講義として追加。大学名・先生の名前は自動で伏せ字（●●／〇〇大学） |
| スライド | 講義の要点を16:9のスライドで表示。スライドイン／フェード／ズームの切り替え、順番に出るアニメーション、自動再生、全画面、スワイプ |
| 要点の強調 | 重要な語句は濃い色の太字で表示し、スクロールすると下線が引かれる |
| 背景の模様 | 白地にパステルの多角形模様。カーソル・スクロールで色が変わり、ウェーブ／ばらける／マグネットの3つの動きを選べる |
| 背景の変化 | 下にスクロールすると、セクションごとに背景の色調が切り替わる |
| レポート作成 | 資料を段階的に分析 → 整理した内容 → 企業の具体例と体験談つきのレポート案3つ → 1000字（字数は変更可）の下書き |
| フォルダ | 作ったレポートを科目ごとのフォルダに保存。Word（.docx）／Excel（.xlsx）で書き出し |
| 通知 | 保存すると「10/23 マーケティング戦略論 レポート作成完了」のように通知。締切の3日前・前日・当日にもお知らせ |
| カレンダー | 課題を色付きで登録。Googleカレンダーに追加、.icsファイルで他のカレンダーに取り込み |
| PC・スマホ | スマホの縦・横どちらでも崩れないレイアウト |

## GitHubで公開する手順（VS Code）

1. このZipを展開し、`repotomo` フォルダを VS Code にドラッグして開きます。
2. 左の「ソース管理」→「GitHub に公開」を押し、公開リポジトリとして作成します。
   （コマンドで行う場合）
   ```bash
   git init
   git add .
   git commit -m "RepoTomo 初版"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/repotomo.git
   git push -u origin main
   ```
3. GitHub のリポジトリで **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save します。
4. 1〜2分後に `https://<あなたのユーザー名>.github.io/repotomo/` で開けます。このURLを送れば、誰でもアクセスできます。

ファイルを直したら、VS Code で「コミット → 同期（プッシュ）」するだけで公開ページも更新されます。

> ローカルで試すときは、フォルダで `python3 -m http.server` を実行し、`http://localhost:8000` を開いてください（`index.html` を直接ダブルクリックでも大部分は動きます）。

## AI分析を使うには

- **Claude のアーティファクトとして開いた場合**：あなたの Claude アカウントで分析します。最初に1回だけ許可を求められます。
- **GitHub Pages で開いた場合**：「分析エンジン」欄の「Claude APIキーを使う」に、自分の Anthropic API キーを入れると AI 分析になります。キーはそのブラウザにだけ保存されます。**キーをコードに書き込んだり、GitHub にアップロードしたりしないでください。**
- **キーがない場合**：オフライン分析（キーワード・課題・締切の検出と、【 】を埋めるテンプレート下書き）で動きます。

## 講義を追加する方法

- **画面から**：講義ライブラリにPDFをドロップするだけです（このブラウザ／アカウントに保存）。
- **コードで（全員に見せたい講義）**：`js/lectures.js` の配列に、同じ形のオブジェクトを1つ追加します。
  `[[ ]]` で囲んだ語句は強調表示（色付きの太字＋下線）になります。スライドの種類（title / points / flow / grid / compare / table / task）はファイル冒頭の説明を見てください。

## データの保存場所

- GitHub Pages：そのブラウザの localStorage（別の端末へはフッターの「バックアップ」で移せます）
- Claude のアーティファクト：あなたの Claude アカウントの保存領域

## カレンダーとの同期について

- **Googleカレンダー**：各予定の「Google」ボタンで、そのままGoogleカレンダーに追加できます。
- **iPhone／Outlook など**：「すべての予定を書き出す（.ics）」で作ったファイルを開くと取り込めます（前日のアラーム付き）。
- 自動で双方向に同期するには、Google Calendar API のログイン（OAuth）設定が必要です。将来の拡張候補です。

## フォルダ構成

```
repotomo/
├─ index.html        画面
├─ css/style.css     デザイン（デザイン（白基調・パステルの多角形模様）とアニメーション）
├─ js/lectures.js    講義データ（大学名・教員名は伏せ字）
├─ js/store.js       保存
├─ js/engine.js      資料の読み込み・匿名化・分析・AI
├─ js/export.js      Word／Excel／カレンダー書き出し
└─ js/app.js         画面の動き
```

使用ライブラリ：JSZip 3.10.1、PDF.js 3.11.174（どちらも cdnjs から読み込み）
